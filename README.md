# Traffic Planner Toolkit

## Version 0.4

Traffic Counter Module.

### Features
- Editable road names
- Selectable directions
- Light vehicle, heavy vehicle, bus, and pedestrian counts
- Live vehicle counts on buttons
- Direction totals
- Road totals
- Overall total
- Undo last tap
- Clear all counts
- CSV export with summary and raw records

### Files
- index.html = app structure
- style.css = app styling
- script.js = app logic
